# Maria's Developer Portfolio

A single-page portfolio that introduces me, my skills and my four projects, built so a recruiter can judge my work in under a minute.

## Live demo

Add your Vercel link here after deploying.

## Tech stack and features

- Next.js (App Router), React, plain CSS
- Six sections: hero intro, about, skills, projects, contact, resume
- Project cards with screenshots, feature lists, live demo and source links
- Responsive layout, one-click PDF resume download

## Setup

```
npm install
npm run dev
```

Open http://localhost:3000. Edit `app/data.js` to change the content, put project screenshots in `public/projects` and the resume in `public/resume.pdf`.
